Scheduling model

How it works

Nityaga RTOS uses fixed-priority preemptive scheduling with optional round-robin within priority levels. Tasks declare periods and deadlines. The kernel enforces hard bounds on interrupt latency and context-switch time.

Core mechanisms

  • Priority inheritance on mutexes prevents unbounded priority inversion
  • Tickless idle reduces power draw on battery nodes
  • Watchdog integration and software monitors detect deadline misses
  • Fail-safe defaults hold actuators in known-safe states on fault

Internal scheduling algorithms, timing analysis methods, and kernel data structures remain confidential.
