# Nityaga RTOS Website

Public high-security website for **Nityaga RTOS** — Real-Time Operating System for Agriculture Technology.

Developed by **Agriculture Service of Product Farm (ASPF)**.

## Features of this site

- Clean, professional design modeled after the AUDP-ECM research portal
- Animated real-time scheduler visualization (motion design)
- Sections covering purpose, capabilities, architecture, agricultural applications, and engineering quality
- Fully static, no tracking, no third-party scripts

## Live site

Once GitHub Pages is enabled (Settings → Pages → Deploy from branch `main` / root), the site will be available at:
