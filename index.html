What it is

Agricultural control loops require guarantees that general-purpose systems cannot provide. Soil moisture sensors must trigger valves within hard deadlines. Machinery actuators and drone flight stacks demand bounded interrupt latency. Nityaga RTOS is the software layer that enforces these timing constraints before decisions reach actuators or research pipelines.

Detect

Runtime monitors and watchdog timers reveal priority inversion and deadline misses.

Schedule

Fixed-priority preemptive scheduling. Round-robin within equal priorities. Rate-monotonic and earliest-deadline-first options available.

Protect

Stack guards, optional MPU isolation, and fail-safe defaults that hold actuators in safe states.

Not a general-purpose OS. Nityaga is purpose-built for deterministic agricultural control. It does not provide non-deterministic services.

Architecture

Classic microkernel-style design optimized for resource-constrained agricultural controllers (ARM Cortex-M, RISC-V, selected ARM64).

  • Minimal kernel with deterministic scheduling core
  • User-level tasks with optional isolation
  • Drivers for common agricultural peripherals (Modbus, CAN, RS-485, PWM, ADC)
  • Integration points for ASPF AUDP-ECM and AUDP-DSP layers
// Example: Periodic soil moisture task
void soil_moisture_task(void *arg) {
    for (;;) {
        float moisture = read_capacitive_sensor();
        if (moisture < THRESHOLD) actuate_valve(OPEN);
        nityaga_delay_until_next_period(1000); // hard 1 Hz
    }
}

Engineering quality

  • Extensive unit and hardware-in-the-loop testing on representative boards
  • Static analysis and formal timing analysis for critical paths
  • Cross-platform continuous integration including ARM64 and RISC-V
  • No telemetry or tracking
