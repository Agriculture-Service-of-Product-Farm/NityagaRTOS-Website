Nityaga RTOS is a hard real-time operating system designed for agricultural cyber-physical systems. It provides predictable scheduling, low-latency interrupt handling, and memory safety guarantees required for irrigation control, autonomous machinery, drone flight stacks, and dense IoT sensor networks.

It is developed by Agriculture Service of Product Farm (ASPF) as part of its agriculture research and innovation work.

What it is

Agricultural systems increasingly rely on closed-loop control: soil moisture sensors trigger valves, NPK probes adjust fertigation, drones maintain formation, and machinery actuators must respond within hard deadlines. General-purpose operating systems introduce jitter that can damage crops, waste water, or create unsafe conditions.

Nityaga RTOS is the software layer that guarantees timing bounds before control decisions reach actuators or research analysis pipelines.

Detect

Priority inversion and deadline misses are detected via runtime monitors and watchdog timers.

Schedule

Fixed-priority preemptive scheduling with rate-monotonic and earliest-deadline-first options. Round-robin within equal priorities.

Protect

Stack overflow guards, MPU isolation where available, and fail-safe modes that default to safe actuator states.

Not a general-purpose OS. Nityaga is purpose-built for deterministic agricultural control. It does not provide a full desktop environment or non-deterministic services.

Architecture

Nityaga follows a classic microkernel-style RTOS design optimized for resource-constrained agricultural controllers (ARM Cortex-M, RISC-V, and selected ARM64 platforms).

  • Minimal kernel with deterministic scheduling core
  • User-level tasks with optional isolation
  • Device drivers for common agricultural peripherals (Modbus, CAN, RS-485, PWM, ADC)
  • Integration points for ASPF’s AUDP-ECM error correction and AUDP-DSP signal processing layers
// Example: Periodic soil moisture task
void soil_moisture_task(void *arg) {
    for (;;) {
        float moisture = read_capacitive_sensor();
        if (moisture < THRESHOLD) {
            actuate_valve(OPEN);
        }
        nityaga_delay_until_next_period(1000); // 1 Hz, hard deadline
    }
}

Agricultural applications

Irrigation & fertigation

Deterministic valve and pump control with guaranteed response to moisture and NPK readings.

Autonomous machinery

Real-time motor control and safety interlocks for tractors, sprayers, and harvesting equipment.

Drone & aerial platforms

Flight control loops and payload actuation with hard timing bounds.

Dense sensor networks

Low-power, synchronized sampling across LoRa or wired field buses with error-corrected telemetry.

Engineering quality

  • Memory-safe by construction in the kernel core; no undefined behavior in scheduling paths
  • Extensive unit and hardware-in-the-loop testing on representative agricultural boards
  • Static analysis and formal timing analysis for critical paths
  • Cross-platform continuous integration including ARM64 and RISC-V targets
  • No telemetry or tracking in the RTOS itself
